# Dev Tao Org

Press Cmd+Shift+D in a file to compare it with this worktree's review base. On first use, choose a branch; main is preselected when available. The selection is remembered across editor restarts. Run **Dev Tao: Change Diff Base** to choose another branch. Canceling leaves the selection unchanged.

Cmd+Shift+B in the Tao repository builds and installs both Dev Tao Org and Tao Language Support into Cursor and VS Code. The comparison uses GitLens, which is declared as an extension dependency.
