# Tao Language Design Examples

- Default to including a short code snippet showing how the proposed functionality would look
  or behave from a Tao author's perspective.
- Illustrations may use pseudocode, incomplete syntax and features Tao does not currently support;
  syntactic correctness is not required. Briefly label proposed syntax or pseudocode so it is not
  mistaken for implemented, executable Tao.
- When discussing file layouts, or when layout materially affects the design, default to a small
  suggested file tree showing only the relevant files and folders.
- Keep snippets, trees and accompanying explanation terse and minimal: just enough to demonstrate
  the point, without full implementations or repeated scaffolding.
